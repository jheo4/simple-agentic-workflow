## Simple Agentic Workflow (SAW)
This project uses SAW. Core rules: `.saw/protocol.md`, profile: `.saw/profile.md`, packs: `.saw/packs/`.
To start in Copilot Chat: select the `saw-elephant` agent, then run `/saw-setup`, `/saw-brainstorm`, `/saw-spec`, `/saw-review`, `/saw-commit-diff`, `/saw-work`, `/saw-sync`, or `/saw-run`.
